# experiments/ — 問題文・条件設定

- `tasks/*.yaml` に問題の版（variant）を、`*.yaml`（直下）に実験定義を置く。
- 問題は `task_id/variant_id@version` で一意。**既存版の内容（問題文・選択肢・正答・回答形式）を書き換えない。** 変更するときは同じ variant の `version` を上げた新しいエントリを追加する。
- 新しい版を追加したら `uv run python scripts/dev.py lock` で `versions.lock.json` に登録する。既存版の内容変更はロックが拒否する。
- 過去の版は削除しない（保存済みデータの再現に必要）。使わなくなった版は実験定義から参照を外すだけにする。
- 実験条件は参照する版を `task/variant@version` で明示する。「最新版」を暗黙に使わない。
- 制限時間は課題ごとに予備実験の結果から決める（概要書 §4.1）。根拠がない値には YAML コメントで「暫定」と書く。
