# src/cogexp/storage/ — 保存層

- 保存される列はすべて `schema.py` の `TABLES` に定義する。列を追加・変更・削除したら同じ変更で `docs/data_dictionary.md` を更新する（`check` が差分を検出する）。
- 取得するデータの種類を増やしたら、同意文（`experiments/texts/consent.md`）の「取得するデータ」も同じ変更で更新する。同意文にないデータを集めない（概要書 §12.1）。
- 直接識別情報（氏名・メール・電話・住所・IP など）の列を追加しない。必要なら別管理の対応表として、分析データとは別の保存先に設計する。
- 生データ（participants / trials / events）は追記のみ。更新が必要な状態遷移（完了・中断）はイベントとして記録するか、更新対象列を明示する。
- 書き込みは `submission_id` で冪等にする。同じ送信が2回来ても行が増えないこと、重複を検知・記録できることをテストする。
- 同意済みでない参加者の trial/event 書き込みは拒否する。
