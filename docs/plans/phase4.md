# フェーズ4：分析の拡張 実行計画（分析計画を含む）

概要書 §7.4・§7.5・§10・§12.3・§13 フェーズ4に対応する。
**§2〜§4 の分析計画は、予備実験・本実験のデータを見る前に確定する。** 変更する場合は理由を決定事項ログに残す。

## 1. 方針（2026-10-02 ユーザー決定）

| 項目 | 決定 |
| --- | --- |
| 統計の範囲 | 記述（95% 信頼区間・効果量）＋検定・回帰。**すべて探索的分析と明示**し、予備実験の人数では不安定であることを画面に表示する |
| 除外基準 | 中断者・未完了者、画面を離れた試行、極端に速い回答（§3） |
| 出力 | 実験者画面への表示のみ（ファイル出力は既存の生データ CSV のみ） |

## 2. デザインと要因

- 各参加者は 1 条件のみ → **条件間の比較は参加者間**。2 問（リンダ・バットとボール）は参加者内だが、**問題ごとに分けて分析する**（概要書 §3.3：同一の能力を測る課題ではない）。
- 要因は実験定義の条件に `factors` として明示する（暗黙に条件IDから推測しない）。

| 要因 | 水準 | `pilot_v1` での対応 |
| --- | --- | --- |
| `wording`（表現） | `standard` / `reworded` | standard_* / reworded_* |
| `time_limit`（時間制限） | `none` / `limited` | *_nolimit / *_limit |

- 練習課題は分析しない。見直し後の回答（`attempt=revised`）は §4.5 でのみ扱う。

## 3. 前処理と除外基準（事前に固定）

**分析用の回答時間：** ブラウザから操作ログが届いた試行はブラウザ側の回答時間（`submitted_at_client_ms − shown_at_client_ms`）、届かなかった試行はサーバー側の `response_time_ms`。どちらを使ったかを列で残す。

| 段階 | 基準 | 単位 |
| --- | --- | --- |
| E1 | 参加者の状態が `completed` でない（中断・未完了） | 参加者のすべての試行 |
| E2 | 問題の表示中に画面が非表示だった時間が **合計 3,000 ms 以上**（タブ切替等。検索・計算機の使用の可能性） | 試行 |
| E3 | 回答した試行で、分析用の回答時間が **1,000 ms 未満** | 試行 |

- 判定は E1 → E2 → E3 の順に行い、除外理由は最初に該当したものを記録する。除外件数を条件・理由ごとに必ず表示する。
- 操作ログが届かなかった試行は E2 を判定できない。**除外せず「判定不能」として件数を表示する。**
- 時間切れの試行は回答時間がないため E3 の対象外。
- 見直しの対（§4.5）は、初回・見直し後のどちらかが除外された場合、対ごと除外する。

## 4. 分析（すべて探索的、問題ごと）

### 4.1 正答率

- 分母は判定可能な回答（時間切れを含めない。フェーズ1の決定）。時間切れ率は別に示す。
- 条件ごとの正答率・時間切れ率：**Wilson の 95% 信頼区間**。
- 表現の差（言い換え − 標準）を時間制限の水準ごとに：**Newcombe（Wilson 法）の 95% 信頼区間**。
- ロジスティック回帰：`正答 ~ 表現 × 時間制限`（参照水準：標準・制限なし）。オッズ比と 95% 信頼区間、p 値。人数不足・完全分離で推定できない場合は「推定できない」と表示し、値を出さない。

### 4.2 回答時間

- 条件ごとの中央値と、**順序統計量による中央値の 95% 信頼区間**（分布を仮定しない）。
- 表現の比較は **時間制限の水準ごとに** Mann–Whitney の U 検定、効果量は順位双列相関。
- **時間制限あり／なしの間で回答時間を比較しない。** 制限あり条件では 15 秒で打ち切られる（時間切れは回答時間なし）ため、分布が切断されていて比較が偏る。

### 4.3 確信度

- 条件ごと・正誤ごとの確信度の平均と 95% 信頼区間（t 分布）。
- 正答と誤答の確信度の差（正答 − 誤答）。差が大きいほど、自信と正確さが対応している。

### 4.4 操作ログの指標

- 選択式（リンダ）の軌跡の指標（軌跡長・x 方向転換・初動時間・最終回答以外への進入）、数値入力式（バットとボール）のキー操作の指標、確信度の画面の主・補助指標（[確信度の画面の指標の定義](confidence_metrics_definition.md)）を、条件ごとの中央値と 95% 信頼区間で示す。
- 検定は行わない（記述のみ）。ログが届かなかった試行は欠損として件数を示す。

### 4.5 見直し（見直しあり条件のみ）

- 回答変化率と 95% 信頼区間（Wilson）。初回 → 見直し後の正誤の変化（誤→正・正→誤）の件数。
- 初回と見直し後の正答率の差：**McNemar の正確検定**（対応あり）。

### 4.6 図

- 条件ごとの正答率（点と 95% 信頼区間の誤差棒）。条件は横軸で区別し、色は 1 色（凡例不要）。
- 条件ごとの回答時間の分布（各試行の点と中央値）。

## 5. 実装

| 場所 | 内容 |
| --- | --- |
| `domain/models.py` | 条件の `factors` |
| `analysis/preprocess.py` | 分析用の回答時間、非表示時間、除外の判定と理由 |
